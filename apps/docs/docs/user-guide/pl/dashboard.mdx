# Pulpit

## Dla kogo jest ten moduł

**Pulpit** to ekran startowy po zalogowaniu. Pokazuje podsumowania i skróty z różnych modułów (sprzedaż, klienci, sprawy, zadania). Przydatny dla każdego użytkownika panelu administracyjnego.

## Gdzie znaleźć w systemie

Ścieżka w menu: **Codzienna praca → Pulpit** (pierwsza pozycja) lub adres główny panelu po zalogowaniu.

## Co można zrobić

- Przeglądać widżety przypisane do Twojej roli (np. nowe oferty, nowe sprawy).
- Dostosować układ widżetów (dodawać, usuwać, zmieniać kolejność) — jeśli masz takie uprawnienie.
- Szybko przejść do szczegółów z poziomu widżetu (kliknięcie wiersza lub linku).

## Instrukcje krok po kroku

### Otwarcie pulpitu

1. Zaloguj się do systemu.
2. Po zalogowaniu zobaczysz pulpit z widżetami dostępnymi dla Twojej roli.

### Dostosowanie układu widżetów

1. Na pulpicie włącz tryb **personalizacji** (jeśli jest dostępny na Twoim koncie).
2. Dodaj widżety z katalogu lub usuń niepotrzebne.
3. Przeciągnij widżety, aby zmienić kolejność.
4. Zapisz układ — ustawienia dotyczą tylko Twojego konta.

### Brak widżetu na pulpicie

1. Sprawdź, czy widżet wymaga dodatkowego uprawnienia (np. widżet spraw wymaga dostępu do modułu Sprawy).
2. Jeśli pulpit jest pusty, użyj personalizacji i dodaj widżety ręcznie.
3. W razie potrzeby poproś administratora o przypisanie widżetów do roli.

## Uprawnienia

| Uprawnienie | Co umożliwia |
|-------------|--------------|
| Podgląd pulpitu | Wyświetlenie ekranu startowego |
| Konfiguracja pulpitu | Personalizacja własnego układu widżetów |
| Przypisywanie widżetów (admin) | Domyślny zestaw widżetów dla ról |

## Powiązania z innymi modułami

Pulpit **nie przechowuje danych** — zbiera informacje z modułów: Sprzedaż, Klienci, Sprawy, Zasoby, Zadania. Szczegóły edytujesz w odpowiednim module.

## Częste pytania

**Pytanie:** Nie widzę widżetu „Nowe oferty”.  
**Odpowiedź:** Twoja rola może nie mieć dostępu do modułu sprzedaży lub do tego konkretnego widżetu.

**Pytanie:** Pulpit jest pusty po pierwszym logowaniu.  
**Odpowiedź:** Dodaj widżety w trybie personalizacji lub poproś administratora o konfigurację domyślnego układu.
